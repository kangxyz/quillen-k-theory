# Comma category comparisons

The universe-lifting files retain the original structured/costructured arrows,
strict up/down functors, projections and transitions, with independent object
and morphism universes. The common-universe comma equivalence also preserves
its original small model.

`Transitions` retains the original common small-category hypotheses for the
canonical structure-arrow transformations and pre/postcomposition functors.
Its projection, composition, opposite and natural-isomorphism comparisons are
categorical; classifying-space maps and homotopy-equivalence hypotheses remain
downstream. Historical declaration namespaces are preserved.
