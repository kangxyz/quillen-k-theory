# Tensor functor comparisons

`Associativity` retains the original associator as the left/right tensor
commutation map and as the comparison between composed left tensor functors.
`Factorization` adds specified parameter changes and braided right/left
factorizations. `Iteration` retains the original groupoid assumptions and
finite-iterate associator/braiding isomorphisms.

The companion `Monoidal/Action/RightTensorLinear` interface gives the actual
inverse-associator lineator and its recursive iterates. Concrete monoidal
translation-telescope models and the selected group-completion comparison
tracks remain downstream.
