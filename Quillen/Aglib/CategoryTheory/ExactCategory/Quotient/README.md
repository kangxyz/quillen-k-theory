# Quotients of exact categories

`Basic` constructs the genuine categorical localization at the relative weak
isomorphisms and its original universal functor. The ambient category is
preadditive with finite biproducts and a specified exact structure; relative
weak isomorphisms use the actual admissible subquotients.

Right filtering supplies right fractions, the stated preadditive structure
and preservation of kernels. Left filtering supplies the dual cokernel and
epimorphism conclusions. `Conflations` defines sequences isomorphic to images
of ambient conflations and proves their kernel/cokernel universal properties
under the respective hypotheses. It does not package the still-unproved
quotient exact-structure axioms. `Descent` retains the original exact functor
vanishing on the specified subcategory.
