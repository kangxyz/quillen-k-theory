# Pair candidates

Objects are actual open immersions of schemes, with arbitrary commutative pair squares. The qc subcategory requires only the ambient scheme to be quasi-compact. Fixed affine coefficient pullbacks give the original strict open functor and compactness after base change, without a flatness premise.

These local general-theory candidates preserve the existing declaration namespaces, hypotheses and universes. Their K-theory applications remain in downstream modules.
