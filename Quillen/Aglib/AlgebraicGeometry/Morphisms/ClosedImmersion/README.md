# ClosedImmersion candidates

The genuine closed-immersion category and its locally noetherian full subcategory retain the original schemes and maps. A closed source over a noetherian target is noetherian. The actual affine, principal and global closed schemes and open complements retain the original quotient and inclusion maps.

These local general-theory candidates preserve the existing declaration namespaces, hypotheses and universes. Their K-theory applications remain in downstream modules.
