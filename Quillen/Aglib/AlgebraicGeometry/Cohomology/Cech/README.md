# Cech candidates

`AffineSectionsCone` identifies the associated module cone with the genuine shifted sheaf cone for quasicoherent affine endpoints, using the actual tilde counits.

These local general-theory candidates preserve the existing declaration namespaces, hypotheses and universes. Their K-theory applications remain in downstream modules.
