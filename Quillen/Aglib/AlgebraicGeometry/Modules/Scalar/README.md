# Scalar candidates

Global sections and units define actual module-sheaf scalar maps. Their multiplication, pullback, open restriction, unit pushforward and trivialization formulas retain the original sheaf morphisms.

These local general-theory candidates preserve the existing declaration namespaces, hypotheses and universes. Their K-theory applications remain in downstream modules.
