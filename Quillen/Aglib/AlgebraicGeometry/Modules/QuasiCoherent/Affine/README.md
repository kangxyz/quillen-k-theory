# Actual affine sheaf denominators and finite-free lifts

SectionDenominators retains a genuine quasicoherent section on the prescribed principal open,
its scalar-power denominator and the original unit-sheaf map/restriction equations. FiniteFreeLift
uses the original epimorphism of quasicoherent sheaves and finiteness of target global sections
to give a finite-free source surjective after the specified composite.
