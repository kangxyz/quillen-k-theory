# Affine perfect-complex candidates

## Local candidate interfaces

The original associated-sheaf and sections interfaces use bounded finite-projective module
complexes over arbitrary commutative rings. The implementations supply strictification, the
perfect derived equivalence, actual chain representatives, principal/finite-principal denominators,
supported roofs and factorization, approximations, stabilized extension and actual complements.

Compact-open, explicit lower/upper term or cohomology bounds, termwise quasicoherence and
support assumptions remain on their original statements. LowerModels retains exact strict term
windows and only the stated top-homology finiteness; it makes no lower-homology finiteness claim
over noncoherent rings. Ordinary affine complex/derived comparison operations live in the
adjacent Modules/Complex/Affine and Modules/DerivedCategory/Affine owners.
