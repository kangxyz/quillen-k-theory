# Bivariate polynomial regularity

`BivariateRegular` retains the four original regularity statements for
`u - v`, `u*v - 1`, `1 - u*v`, and `v - u` in an iterated polynomial ring over
an arbitrary commutative ring. The coefficient arguments add no domain or
nonzero-ring hypothesis. Historic declaration names are retained; actual
projective-line incidence maps remain downstream.
