# Mapping cone comparisons

The original cone maps give actual isomorphisms of commuting squares,
binary-biproduct comparisons and the stated source-sign change. `Parametrix`
uses specified reverse maps and defect identities to construct genuine cone
homotopies and a homotopy equivalence, with no finiteness hypothesis.

The additive statements use a preadditive category with the specified binary
biproducts. `Projector` uses the original derived category of an abelian
category; `SingleFunctor` retains the additive functor, single-complex maps
and explicit shift. Canonical Aglib cone APIs are imported directly.
