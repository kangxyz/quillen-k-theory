# Polynomial and Laurent ring functors

`PolynomialLaurentFunctor` retains the actual polynomial and Laurent
endofunctors on commutative rings, coefficient maps, and the plus and inverse
coordinate natural transformations. Their coefficient naturality and original
commuting equations use no noetherian, domain or nonzero-ring assumption.
The original `Quillen.Bass` declaration names are preserved; actual Bass
contractions and K/spectrum diagrams remain downstream.
