# Matsumoto interface clients

`WeylTransporter.lean` checks a positive three-cycle between different adjacent
indices, a variable diagonal ratio and the actual central fourth power.
`RootSections.lean` checks the identity projection to actual two-dimensional GL,
the transported lower root and its rational diagonal covariance. These are
client tests; production modules do not import them.

`FiniteRootLifting.lean` retains the original five-dimensional literal-root-law
and ordered-sign regression client.
